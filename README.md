# ポケカ シティリーグ週次レポート

このrepositoryは、公開用の週次レポートを保存する場所です。

現在の [過去データ試運転](rehearsal/2026-02-12/weekly_facts_report.html) は、保存済みの2026-02-12終了分を再集計した閲覧用trialです。2027シーズンの正式週次レポート、公式収集の完全性、デッキ分類の承認を表すものではありません。

人の評価が`未確認`と表示される箇所は、保存済み事実から作った機械候補を人がレビュー・承認していないことを示します。推奨、分類の確定、対面判断、更新の確定ではありません。

正式運用を開始できる状態になった後の週次ページは、repository rootの`YYYY-MM-DD/`に保存します。過去データtrialは正式ページと区別するため、`rehearsal/YYYY-MM-DD/`にのみ置きます。
